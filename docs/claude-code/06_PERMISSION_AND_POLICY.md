# Permission And Policy

## General Rule
권한은 필요한 순간에 요청한다. 피보호자에게 한 번에 많은 권한을 요구하지 않는다.

## MVP Initial Permission
첫 온보딩에서는 기본 런처 설정만 먼저 요청한다.

Do:
- 런처 설정 안내
- Android 기본 홈 앱 설정 팝업

Do not:
- 위치 권한 요청
- 전화 상태 권한 요청
- 알림 권한 요청
- 백그라운드 위치 권한 요청

## Notification Permission
알림 권한은 가족 연결 시점에 요청한다.

사용 목적:
- 가족 메시지
- 보호자 연결 알림
- 유료 기능 동의 요청

## Paid Permission Flow
안심 케어 결제 후 피보호자 동의가 필요하다.

1. 보호자 결제
2. 피보호자 폰에 동의 화면 표시
3. 피보호자가 허락
4. 시스템 권한 요청
5. 기능 활성화

거절 시:
- 안심 케어 기능 비활성화
- 보호자에게 거절 안내
- 결제 자동 환불 상태로 전환
- 무료 기능은 유지

## Location
유료 기능.

MVP 기준:
- 5분 주기 위치 확인
- 실시간 추적이라고 표현하지 않는다.
- 백그라운드 위치 권한이 필요하다.

권한 거절:
- 위치 기능 OFF
- 보호자에게 `부모님이 위치 권한을 허락하지 않았어요` 안내

## Phone State
유료 기능.

MVP 정의:
- 연락처에 없는 번호로 통화가 발생하면 보호자에게 알림
- 통화 내용 분석은 하지 않는다.
- 스팸 DB 연동은 하지 않는다.

## Installed Apps
유료 앱 설치 감지와 무료 앱 목록 읽기 모두 Android 정책 확인이 필요하다.

MVP 접근:
- 런처 앱으로서 설치된 앱 목록 읽기를 시도한다.
- 정책 리스크가 있으면 사용자 선택 앱만 등록하는 fallback을 준비한다.

## Emergency Sound
유료 기능.

주의:
- OS 정책상 강제 재생은 제한될 수 있다.
- 실제 구현 전에는 interface와 UI만 분리한다.
- 권한/정책 문제 발생 시 일반 푸시 + 알림음 fallback을 둔다.

## SOS Call
무료 기능.

정책:
- 앱에서 바로 119/112로 전화하지 않는다.
- 전화 앱에 번호를 표시한다.
- 사용자가 통화 버튼을 한 번 더 눌러야 한다.
