# Screen Spec

## Design Principle
피보호자 앱과 보호자 앱은 완전히 다른 톤을 가진다.

피보호자 앱:
- 큰 글씨
- 큰 버튼
- 적은 선택지
- 난색 기반 팔레트
- 색 + 아이콘 + 텍스트 3중 표현
- 깊이 1단계 우선

보호자 앱:
- 흰 배경
- 파란 포인트
- 일반 관리 앱처럼 깔끔한 UI
- 정보 밀도는 피보호자 앱보다 높아도 된다.

## 피보호자 첫 실행
화면:
- 앱 이름: 잘보이네
- 설명: 어르신을 위한 쉬운 스마트폰
- 큰 버튼: 시작하기
- 작은 안내: 가족 및 어르신을 도와주시는 분은 여기를 눌러주세요

## 화면 선택
카드 2개:
- 정말 쉬운 화면
- 자세한 화면

각 카드:
- 미리보기 이미지 또는 간단한 mock
- 큰 제목
- 짧은 설명
- 선택 버튼

선택 즉시 확정된다. 추가 질문은 없다.

## 정말 쉬운 화면
상단:
- 시간
- 날짜
- 진동/벨 상태

중앙:
- 2x2 큰 버튼
- 전화
- 문자
- 앨범
- 영상 보기

하단:
- 가족 연결 또는 자녀 이름 버튼
- SOS
- 더 보기

## 자세한 화면
상단:
- 시간
- 날짜
- 진동/벨 전환

중앙:
- 2열 버튼 배열
- 전화
- 문자
- 카카오톡
- 영상 보기
- 사진찍기
- 사진 보기
- 더 추가하기 슬롯

하단 탭:
- 첫 화면
- 설정
- SOS

## SOS 화면
버튼:
- 119
- 112
- 보호자

동작:
- 번호 선택 시 전화 앱을 연다.
- 즉시 전화하지 않는다.
- 사용자가 통화 버튼을 한 번 더 눌러야 한다.

## 보호자 대시보드
하단 탭:
- 홈 관리
- 메시지
- 안심
- 설정

상단 고정 카드:
- 현재 선택된 부모님 이름
- 배터리
- 소리 모드
- 연결 상태
- 마지막 갱신 시간

가족 플랜일 때:
- 부모님 이름 드롭다운
- 엄마 김옥순
- 아버지 박영철
- + 부모님 추가

## 홈 관리 탭
기능:
- 현재 홈 버튼 목록
- 드래그 순서 변경
- 이름 수정
- 삭제
- 앱 추가
- 버튼 색상 변경
- 글씨 크기 변경
- 화면 모드 변경

## 메시지 탭
기능:
- 카톡 스타일 대화
- 텍스트 전송
- 이미지 전송
- 무료 잔여 횟수 표시
- 유료 전환 안내

## 안심 탭
미결제:
- 유료 기능 목록
- 잠금 표시
- 안심 케어 시작하기

결제 후:
- 위치 확인
- 연락처에 없는 번호 통화 알림
- 앱 설치 감지
- 폰 미사용 알림
- 배터리 부족 알림
- 긴급 소리 보내기

## 설정 탭
기능:
- 긴급 연락처
- 가족 연결 관리
- 가족 보호자 초대
- 부모님 폰 다시 연결
- 대표 보호자 변경
- 가족 플랜 / 부모님 추가
- 부모님 정보
- 로그아웃
